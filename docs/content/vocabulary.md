# Vocabulary

Four tutorials that teach writing and extending a kernel's own vocabulary,
end to end: declaring a shared shape once for a family of kernels, growing
it by ordinary Python inheritance, giving a function a derivative you
supply, and a capstone that runs the whole machinery at scale and hands it
to PyTorch. Two further pages round it out: the decision between a
primitive, `raw_device`, and a native op, and the contributor path for the
last of those.
