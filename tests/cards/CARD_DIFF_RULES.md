## Node families the transform owns

| family | treatment |
|---|---|
| `accum_write` | reverse = gather of its adjoint plane |
| `assign` | seeded from an adjoint plane / mirrored as a tangent sink |
| `at` | reverse = scatter-add AccumWrite; forward = tangent lookup |
| `constant` | terminal: zero flow |
| `dispatch` | : K INDEPENDENT per-branch reverse passes combined into ONE adjoint dispatch per leaf reached, SAME policy as the primal; forward mirrors the branches under that same policy; `kind` itself is an address, not a differentiable quantity, and receives no adjoint |
| `leaf` | terminal: a gradient/tangent plane, not a rule |
| `loop` | MIRRORED, not folded: an accumulator loop's reverse is a forward loop storing nothing; a recurrence's runs backwards over the forward loop's own per-iteration carries; forward mode is ONE loop carrying primal and tangent together (hawk/diff/loops.py) |
| `loop_carry` | terminal INSIDE the body: its adjoint is what the reverse loop carries, and its tangent what the augmented loop does |
| `loop_index` | terminal: a loop's own index is an address, not a differentiable quantity (SampleIndex's treatment) |
| `loop_value` | the projection of one carried slot: its adjoint SEEDS the loop it came from, and its tangent is the augmented loop's matching slot; never a rule of its own |
| `mapreduce_partial` | reverse = broadcast of a rank-0 'sum' adjoint |
| `primitive` | the AUTHOR's supplied rule, applied to the boundary's declared inputs; never differentiated through |
| `sample_index` | terminal: an address, not a differentiable quantity |
| `tape_read` | the forward loop's carried value at one iteration — the ONE thing a reverse recurrence needs and the only reason a bounded local array is declared at all |
| `wide_write` | seeded from an adjoint plane / mirrored as a tangent sink |
